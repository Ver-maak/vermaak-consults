# Vermaak Nexus

Build a modern, professional, responsive website for **Vermaak Consults**, the consultancy arm of Vermaak, an Africa-focused creative economy, digital transformation, innovation and workforce development company.

## 1. Brand Positioning

**Company Name:** Vermaak Consults

**Parent Brand:** Vermaak

**Website Purpose:** Position Vermaak Consults as a credible consultancy partner for governments, development organisations, NGOs, private-sector organisations, SMEs, startups, creative enterprises and youth-focused programmes.

**Core positioning statement:**

> Vermaak Consults helps organisations, enterprises and development programmes design, implement and scale innovative solutions across digital transformation, enterprise development, creative economy, research, learning and workforce development.

The website should communicate that Vermaak is **practical, innovative, African-focused, technology-enabled and results-oriented**.

Do NOT make the website look like a traditional old-fashioned consultancy firm. It should feel like a modern African innovation company that combines consulting, technology, creativity and implementation.

---

# 2. Visual Direction

Create a clean, premium and contemporary design.

Use:

* Strong typography
* Large headings
* Generous whitespace
* Subtle animations
* Modern cards

* High-quality African business/technology imagery
* Minimal gradients
* Professional but youthful aesthetic

The design should communicate:

**Strategy + Technology + Creativity + Impact**

Use a sophisticated colour palette that complements the existing Vermaak brand. Prefer a primarily dark/neutral foundation with a strong Vermaak accent colour. Avoid excessive colours.

The website must be fully responsive on:

* Desktop
* Tablet
* Mobile

Use subtle scroll animations and hover effects, but do not over-animate the site.

## Deploying to Netlify

This repo is pre-configured for Netlify: `netlify.toml` sets the build command and output folders, and `vite.config.ts` switches the production build to Netlify's serverless format when built outside Lovable.

1. In Netlify, choose **Add new site → Import an existing project** and connect this Git repository.
2. Netlify auto-detects the settings from `netlify.toml` (build `npm run build`, publish `.output/public`) — no changes needed.
3. Click **Deploy**. SSR pages run as a Netlify Function and static assets are served from the CDN.

Deploys from Lovable's Publish button are unaffected — Lovable hosting keeps using its own build target.
